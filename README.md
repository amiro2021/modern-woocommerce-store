# 🛒 NexusGadget - Modern E-Commerce Store

A high-performance, fully responsive e-commerce web application built using **WordPress** and **WooCommerce**, tailored for modern tech gadgets and accessories.

## 🚀 Key Features
- **Customized UI/UX:** Clean, minimalist design focused on conversion rates and user experience.
- **Advanced Product Catalog:** Interactive product grids with dynamic filtering and attributes.
- **Optimized Checkout Flow:** Streamlined cart and checkout process to minimize cart abandonment.
- **Fully Responsive:** Mobile-first design that looks and performs exceptionally across all devices.

## 🛠️ Tech Stack
- **Core:** WordPress
- **E-Commerce:** WooCommerce
- **Frontend / Layout:** HTML5, CSS3, JavaScript, Elementor
- **Backend & Database:** PHP, MySQL (Local development via Laragon)
